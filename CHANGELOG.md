# Changelog

## 0.1.0 (2026-11-07)

First release. Word pages with zoom, find, tracked changes, an outline and Copy as Markdown. PowerPoint slides with a thumbnail strip, arrow keys, speaker notes, find and Copy as Markdown. A clear message for old .doc and .ppt files. Editor toolbar with zoom, fit, find and Open in Default App. A Help menu item with support links.
