# Changelog

## 0.1.1 (2026-11-07)

- Empty, password-protected and damaged files now get a plain message. Before, some showed a library error such as "Corrupted zip ?" or "Cannot read properties of null".
- A ZIP file that is not a Word or PowerPoint file says which part is missing.
- A deck with no slides shows "No slides" instead of "1 / 0".
- Find shows "5000+" when it stops at 5,000 matches.
- The Context Drift link goes to its GitHub page until the Marketplace listing is public.
- README and description: page breaks and password-protected files are listed as limits.

## 0.1.0 (2026-11-07)

First release. Word pages with zoom, find, tracked changes, an outline and Copy as Markdown. PowerPoint slides with a thumbnail strip, arrow keys, speaker notes, find and Copy as Markdown. A clear message for old .doc and .ppt files. Editor toolbar with zoom, fit, find and Open in Default App. A Help menu item with support links.
